Разметка диска до создания swap файла. Как создавался файл подкачки через zram, выбор пал на zram тк мешала файловая система сделать это через базовые команды fallocate или dd. 
Первая команда sudo modprobe zram она загружает модуль ядра.
Вторая команда sudo zramctl -f -s 2048M, сама команда настраивает устройство zram, zramctl сама утилита -f (find) приказав системе искать свободное место; -s 2048М (макс место). 
Третья команда sudo mkswap /dev/zram0 форматирует созданное пространство как пространство swap. 
Четвертая команда sudo swapon /dev/zram0 активирует устройство как активный файл подкачки. wiki.archlinux.org/title/Zram.

Переходим к созданию пользователей. User мы добавляем через команду useradd -m -s /bin/bash user. -m автоматом создает домашнюю папку, а -s назначает командную оболочку bash.

Далее мы задаем пароли. Используем echo "user:user" | chpasswd (для рута делаем также только меняем имя и пароль соответственно). su - user команда чтобы переключиться с рута на юзера. 
su - переключает пользователя. userdel -r user этой командой мы можем удалить пользователя. 
Что произойдет с данными на диске при выборе автоматической разметки? lsblk через эту команду мы можем посмотреть какие диски у нас есть. 
Если мы выберем автоматическую разметку, то у нас старые данные будут полностью удалены. Стираются все разделы, далее создаются новые разделы под средством форматирования.
